# AI 연결과 직접 호스팅

'AI로 다듬기'는 두 가지 방법으로 쓸 수 있어요.

1. **복사해서 쓰기 (설정 없음):** 다듬기 프롬프트를 복사해 ChatGPT, Claude, Gemini, 로컬 AI 화면 등에 붙여넣습니다.
2. **화면에서 바로 쓰기:** 'AI 연결'에서 OpenAI 호환 주소를 지정하면 이 화면에서 바로 결과를 받아요.

## 1. 실행하기

- **GitHub Pages:** README의 안내대로 공개하면 `https://<계정명>.github.io/<저장소명>/`에서 열립니다.
- **내 PC:** `index.html`을 브라우저로 열거나, 폴더에서 `python3 -m http.server 8000`을 실행하고 `http://localhost:8000`을 엽니다. 파일을 직접 열면 페이지 출처가 `null`로 취급되므로, 로컬 AI 서버가 모든 출처(`*`)를 허용해야 연결돼요.
- **내부망 웹 서버:** 여러 사람이 함께 쓸 때 권장합니다. 파일 하나를 그대로 올리면 됩니다.

글꼴은 Google Fonts에서 불러옵니다. 인터넷이 막힌 내부망에서는 시스템 글꼴로 표시되고 기능에는 영향이 없어요.

## 2. AI 연결하기

1. '아이디어만 있어요' 모드에서 **AI 연결**을 누릅니다.
2. **OpenAI 호환 API**를 고르고, 쓰는 서버 버튼을 눌러 주소를 채웁니다.
3. 모델명을 적습니다. 서버에 올라가 있는 이름 그대로여야 해요. 예를 들어 Ollama는 `ollama list`에 나오는 이름입니다.
4. **연결 테스트**로 확인한 뒤 저장합니다.

| 서버 | 기본 주소 | 브라우저 접근 허용(CORS) |
|---|---|---|
| Ollama | `http://localhost:11434/v1` | 환경변수 `OLLAMA_ORIGINS`에 페이지 출처(또는 `*`)를 넣고 다시 시작 |
| LM Studio | `http://localhost:1234/v1` | 로컬 서버 설정에서 CORS 허용을 켬 |
| llama.cpp (`llama-server`) | `http://localhost:8080/v1` | 버전에 따라 다르므로 연결 테스트로 확인하고, 막히면 앞단 프록시에서 허용 헤더를 추가 |
| vLLM | `http://localhost:8000/v1` | 실행 옵션 `--allowed-origins`로 허용할 출처 지정 |
| LiteLLM 프록시 | `http://localhost:4000/v1` | 프록시 설정에서 허용 출처 확인 |
| OpenRouter, OpenAI | 버튼으로 채워지는 주소 | 브라우저 호출을 지원하지만 API 키가 브라우저에 저장됨 |

서버별 옵션 이름은 버전마다 바뀔 수 있어요. 연결이 안 되면 각 서버의 공식 문서에서 CORS 설정을 확인하세요.

## 3. 연결이 안 될 때

- **"서버에 연결하지 못했어요":** 서버가 켜져 있는지, 주소 끝에 `/v1`이 있는지, CORS가 허용됐는지 확인하세요.
- **https 페이지에서 내부망 서버를 부를 때:** 브라우저는 https 페이지에서 `http://192.168.x.x` 같은 내부망 http 주소로의 요청을 막습니다. 페이지도 같은 내부망의 http로 열거나, AI 서버 앞에 https 프록시를 두세요. `http://localhost`는 대체로 허용되지만, 최근 브라우저는 공개 페이지가 로컬 서버에 접근할 때 허용 여부를 묻는 창을 띄울 수 있어요.
- **"인증에 실패했어요":** API 키를 확인하세요. 로컬 서버는 보통 키가 필요 없어요.
- **결과가 글로만 표시될 때:** 작은 모델이 정해진 JSON 형식을 지키지 못한 경우예요. 받은 답을 그대로 보여주니 내용은 쓸 수 있고, 더 큰 모델로 바꾸면 안정됩니다.

## 4. 기관 배포 권장 구성

```
브라우저 ──> 내부 웹 서버
              ├── /index.html
              └── /llm/v1  ──(프록시)──> AI 라우터 (LiteLLM 등) ──> 내부 모델 / 상용 API
```

- 앱과 라우터를 **같은 도메인**에 두고 하위 경로로 프록시하면 CORS 문제가 생기지 않아요. 앱의 주소 칸에는 `https://내부도메인/llm/v1`처럼 적습니다.
- **API 키는 라우터에만** 두고, 앱 설정의 API 키 칸은 비워 두세요. 키를 브라우저에 저장하는 방식은 개인용까지만 권합니다.
- 미공개 원고나 연구 데이터가 외부로 나가지 않도록, 라우터에서 내부 모델로만 보내게 정할 수 있어요.

## 5. 저장되는 정보

입력한 연구 정보, 저장한 답변, 수정한 프롬프트, AI 연결 설정(API 키 포함)은 브라우저 저장 공간에만 있고 웹 서버로 전송되지 않아요. 'AI로 다듬기'를 누를 때만 아이디어와 선택 항목이 지정한 AI 주소로 전송됩니다. 공용 PC에서는 사용 방법 페이지의 '저장한 내용 모두 지우기'로 정리하세요.

## 6. 업데이트

새 버전의 `index.html`로 파일을 교체하면 됩니다. 브라우저에 저장된 입력값과 답변은 그대로 남아요.
