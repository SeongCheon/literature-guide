AI 연결

'AI로 다듬기'에 쓸 AI를 고르세요. 설정은 이 브라우저에만 저장돼요.

API 키는 이 브라우저에 저장됩니다. 여러 사람이 쓰는 배포라면 키를 서버에 두는 AI 라우터 주소를 넣으세요.

'다듬기 프롬프트 복사'를 누르면 프롬프트가 복사돼요. ChatGPT, Gemini, 로컬 AI 화면 등 쓰는 곳에 붙여넣으면 됩니다.
  1. 출발점을 고르세요논문이 없으면 '아이디어만 있어요', 있으면 '논문을 모았어요'.
  2. 주제와 분야를 적으세요모든 프롬프트에 자동으로 채워집니다.
  3. 단계별로 복사해 붙여넣으세요추천 순서를 따라 AI 대화창에 붙여넣으면 됩니다.
사용 방법 자세히

논문 더미를 연구 질문으로 바꾸는 15개의 프롬프트

주제와 분야를 한 번만 적어 두면 모든 프롬프트에 채워집니다. 특정 단계에만 필요한 정보는 그 단계에서 물어봐요. 논문을 AI에 올린 뒤, 필요한 프롬프트를 골라 복사해 붙여넣으세요.

막연한 아이디어에서 읽을 논문 목록까지

아이디어를 적고 AI로 먼저 다듬어 보세요. 그다음 단계별 프롬프트를 웹 검색이 켜진 대화에 붙여넣으면 선행연구 조사까지 이어집니다.

추천 순서

단계를 누르면 해당 프롬프트가 열려요. 복사한 단계는 채워집니다.

      수정됨

      논문은 먼저, 프롬프트는 나중에

      PDF를 모두 업로드한 다음 프롬프트를 붙여넣으세요. 한 대화에서 1번으로 전체를 읽힌 뒤 이어서 쓰면 맥락이 유지돼 결과가 더 일관됩니다.

      노란 테두리는 빈칸이에요

      비어 있는 변수는 프롬프트 안에 노란 테두리로 표시됩니다. 눌러서 바로 채울 수 있고, 그대로 복사하면 [주제] 같은 자리표시가 남아요.

      영어 원문이 더 정확할 때가 많아요

      모델은 영어 지시를 더 일관되게 따르는 편입니다. English로 전환해도 '한국어로 답변'을 켜 두면 결과는 한국어로 받아요.

      C단계부터는 웹 검색을 켜세요

      지형 조사, 참신성 점검, 읽기 목록은 실제 문헌을 찾아야 합니다. 사용하는 AI에서 웹 검색이나 리서치 기능을 켠 대화에 붙여넣으세요.

      AI로 다듬기는 검색하지 않아요

      이 페이지의 다듬기 기능은 질문, 키워드, 검색식만 만들어 줍니다. 논문 제목이나 통계는 넣지 않도록 되어 있으니, 문헌은 C단계 이후에 확인하세요.

      서지 정보는 꼭 원문으로 확인

      검색 기반 답변도 제목이나 연도가 틀릴 수 있어요. 읽기 목록의 DOI나 링크를 열어 확인한 뒤 내려받으세요. 학술 DB 활용법은 논문 찾고 내려받기에 정리했어요.
